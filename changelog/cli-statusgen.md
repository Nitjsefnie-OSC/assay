### Changed
- `statusgen` now parses every command line through one Cobra/pflag command tree with a fresh, command-local Viper settings resolution (flag, else default; no environment variable or config file is bound by the command-line layer). Every verb answers `-h`, `--help`, `-help` and `statusgen help <verb>` with generated help on stdout and exit 0, before any roster, configuration, credential or network read; `statusgen version` and `-version` join `--version`. The existing invocation forms keep working: `--flag=value`, `--flag value`, the Go-flag single-dash spellings (`-root X -dora -since D`, `-o`, `-generated`), `--`, repeated list flags and dash-leading values. A parse error (unknown flag or subcommand, bad or missing value) still exits 2 before anything runs, now with one error line and a `--help` pointer instead of the full flag dump. A verb's flags may now follow its positional arguments.
