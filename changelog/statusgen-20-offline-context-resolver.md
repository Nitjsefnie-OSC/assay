### Added
- `statusgen context discover|recheck|check --snapshot DIR [--json]`: an offline resolver over an explicit snapshot directory. It discovers the owners and consumers of a target from declared edges, plan frontmatter, `consumers:` fields, directory enumeration and prose candidates, and emits a context-handoff-v1 receipt that covers architecture only. It rechecks a prior receipt against a new snapshot (preserved / reconcile / hold). It also checks amendment patches: a patch is refused when it is unbound, does not apply exactly, rewrites Evidence or dated history, silently rebinds an active claim, patches a delivered brief, or conflicts with an approved rival. See `docs/context-handoff.md`.
