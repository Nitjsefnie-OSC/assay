### Fixed
- The declared-input-scope reader no longer refuses a `## Context` `files:` entry that has an annotation before its `:` description, such as `` `tools/x/` (new): `main.go`, `server.go` `` (medici-finance/assay#3756). Three briefs that were refused only for this now yield a verification receipt. Two related mistakes in the same reader are also fixed. An annotation written straight after an unquoted path, as in `repairobligation.go(planned)`, was read as part of the file name, so the real file fell out of the brief's scope. The word "tests" in "and tests (new)" was read as a path named `tests`. Garbage around an annotation is still refused.
