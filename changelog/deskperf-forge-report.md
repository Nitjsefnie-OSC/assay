### Added
- `deskperf report` gains a forge-calls section, per tool and per release build: total forge calls, calls per run (p50 / p90 / max), each row's share of all forge calls, and the rate-limit pressure against the 5000-per-hour App budget floor (busiest UTC hour and the p90 run; a gauge pooled over every tool and installation, not a bound). It reads perf-v1 `forgeCalls` and the perf-v2 `http` counter; a run whose counter was not observed — including a `statusgen` record, whose 0 is documented as "not counted" — is reported as unavailable, never as zero. Rows key on the validated tool label and build stamp, so a malformed record groups under `other` or `unpinned` and never prints its raw text.
